# 法安智治

基于多模态识别的市域网络风险监测与涉网纠纷智能调解一体化平台

## 项目简介
面向市域基层治理，打造“事前风险监测预警 - 事中矛盾干预化解 - 事后纠纷智能调解”全流程闭环平台。轻量化、低成本，为政法单位及广大网民提供网络治理与维权服务。

## 团队
- 大一跨专业团队（网络空间安全、法学、大数据、行政管理）
- 双导师制：校内学术导师 + 司法局行业导师

## 技术栈
- 多模态识别：Qwen3-VL
- AI 法律大模型：北大法宝开源模型
- 区块链存证：对接蚂蚁链、最高法司法链
- 大数据处理：Hadoop/Spark 轻量版

## 大赛信息
- 赛道：互联网+ 大学生创新创业大赛 高教主赛道
- 组别：创意组
- 周期：2026 - 2029
