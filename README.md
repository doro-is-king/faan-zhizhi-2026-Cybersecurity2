# 法安智治 | Faan Zhizhi

> 技术赋能基层法治，青春守护网络平安

基于多模态识别的市域网络风险监测与涉网纠纷智能调解一体化平台。
实现 **事前预警 - 事中干预 - 事后化解** 全流程闭环，服务基层数字法治。

- 🔍 多模态网络风险监测（图文音视频融合识别）

- 🔗 监测-调解一体化协同中台（数据互通、流程闭环）
